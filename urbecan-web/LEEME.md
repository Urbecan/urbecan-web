# Web Urbecan — versión provisional

Esta carpeta es la web completa, lista para publicar.

## Publicar en Netlify (sin GitHub, 1 minuto)
1. Entra en https://app.netlify.com/drop
2. Arrastra esta carpeta entera.
3. Te da una dirección tipo xxxx.netlify.app → en Site settings puedes cambiarla a urbecan.netlify.app.

## Publicar desde GitHub (organización Urbecan)
1. En github.com/Urbecan → New repository → nombre: urbecan-web → Create.
2. "uploading an existing file" → arrastra el contenido de esta carpeta → Commit.
3. En Netlify: Add new site → Import from GitHub → urbecan-web → Deploy.
   Cada cambio que se suba a GitHub se publica solo.

## Mientras sea provisional
La web está oculta a Google (robots.txt + meta noindex).
Al pasar al dominio definitivo hay que quitar ambas cosas.
