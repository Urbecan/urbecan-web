# Web Urbecan

Estructura:
- index.html → Inicio
- nosotros/, particulares/, profesionales/, contacto/ → páginas principales
- aviso-legal/, privacidad/, cookies/, gracias/ → secundarias
- 404.html → página no encontrada
- assets/css, assets/js, assets/img → estilos, código y fotos

Mientras sea provisional, está oculta a Google:
- robots.txt (Disallow: /)
- <meta name="robots" content="noindex,nofollow"> en cada página

Al lanzar en urbecan.com: quitar ambas cosas y añadir en robots.txt
Sitemap: https://www.urbecan.com/sitemap.xml
